# TSCN branding

The visual reference is the unit's [Join website](https://join.tscnlab.org/), with source at [tscnlab/website-join](https://github.com/tscnlab/website-join). The directory uses its existing colours, Georgia headings, system sans-serif body font and restrained borders. No external font service is required.

## Social preview

`social-preview.png` is the 1200 × 630 sharing image, adapted from the [Join website template](https://github.com/tscnlab/website-join/blob/main/templates/social-preview.html), using the same unchanged unit logo, layout, colours and typography. The title and URL identify the light logger directory. Its source is `social-preview.html`; run `node scripts/render-social-preview.cjs` from the project root to regenerate it. The PNG is checked in so normal Quarto builds do not need a browser. Quarto emits Open Graph and large-image Twitter Card metadata for both pages.

## Device wireframes

These historical assets are retained in the source project for provenance. They are not displayed, copied as website resources, or generated during the Quarto build.

The SVG drawings in `devices/` were generated by `scripts/device_wireframes.py`. They were drawn from inspected device photographs and diagrams, with case outlines, windows, displays and mounting details simplified for use at icon size. They are not to scale or manufacturer-approved engineering drawings.

Each device's visual sources, figure/page locators and caveats are recorded in [`../data/device-illustrations.json`](../data/device-illustrations.json). Most references are journal articles or preprints. The original ActTrust and MotionWatch drawings also use published manufacturer manuals; the original Spectrum uses an ISLSWG flight-research document. These are appearance references only, not additions to the validation evidence.

The version-unspecified GENEActiv entry retains its version uncertainty. A housing drawing does not establish equivalence to GENEActiv Original. LYS and LYS Button are now one catalogue entry; archived illustration metadata predates that correction. No hidden electronics or precise dimensional tolerances are inferred.

## PDF source reader

Mozilla PDF.js 6.5.438 is vendored from the official `pdfjs-dist` npm distribution, with its Apache-2.0 licence, worker, fonts and WebAssembly support. The source code is maintained at https://github.com/mozilla/pdf.js.

The original paper PDFs in `../sources/` are unchanged copies. Author, DOI, source URL, licence, SHA-256 and page count are recorded in `../data/source-evidence.json` and `../data/library.json`. Highlights are separate website annotations, not modifications to the PDFs. Non-redistributed author manuscripts can be opened from the reader’s computer; the OSA paper is loaded from its author repository.
